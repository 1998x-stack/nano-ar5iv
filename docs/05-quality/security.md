# 13｜安全、许可与隔离威胁模型

## 威胁来源

任何上传的 `.tex`、`.sty`、`.cls`、归档文件及引用资源均为不可信输入。TeX 是可编程语言，不能假定“文档”不含危险操作。攻击面包括压缩包解压越界、特殊文件/符号链接、资源耗尽、外部命令执行、读取主机敏感文件、网络外传、复杂宏展开死循环和 SVG/HTML 脚本污染。

## 最小安全边界 [D]

- **Archive extraction**：按文件数、总解压大小、单文件上限、路径深度、压缩比限制；只允许普通文件；归一化并禁止路径穿越；不跟随 symlink/hardlink；拒绝恶意设备/管道类型。
- **Sandbox**：独立临时工作区，非 root 用户，read-only 引擎镜像、独立可写产物目录、no-new-privileges、禁用 shell escape、默认无网络、固定 CPU/内存/PID/磁盘/时间配额。
- **Isolation**：不能直接把宿主机完整 `$(pwd)` 交给任意用户源码；使用经过滤的工作目录复制，防止读取仓库凭据或配置。
- **Policy**：禁止自动拉取不受信任的 .sty/.cls 并在共享主机执行；版本白名单与 SBOM 优先。
- **Content rendering**：HTML/SVG 产物在隔离域或 sandbox iframe 呈现，CSP、禁止脚本/事件 handler 外部链接执行；资源代理必须限制内外网地址访问。
- **Logs**：清理潜在凭据、绝对路径和个人信息；限额存储；可追溯但不公开敏感原文。
- **Retention**：版权/数据许可、用户删除权与保留策略单独管理。

## 威胁→控制→可测试证据

| 风险 | 控制 | 测试 |
|---|---|---|
| tar-slip / zip-slip | 规范路径+拒绝越界 | 含 `../` 条目的归档 |
| symlink escape | 拒绝或严格解析 | 指向工作区外的链 |
| decompression bomb | 解压上限 | 高压缩比生成归档 |
| TeX CPU hang | 时间/进程/内存配额 | 受控递归宏样本 |
| 读系统文件 | 无宿主挂载、独立 UID | 尝试访问沙箱外文件 |
| 任意网络请求 | 禁出站网络 | 出站访问被拒 |
| HTML XSS | 安全呈现+消毒+隔离 | 不可信标签脚本样本 |
| 外部二进制资源 | 内容类型验证+隔离 | 伪装扩展名样本 |

## 关于示例命令

官方 ar5ivist README 的 Docker 命令只适用于受控本地工程演示，**不是生产安全基线**。所有真实处理必须首先实现输入隔离、资源限制及安全性验收。

## 法律/许可

仅在有权使用的范围内保存与展示文章衍生内容；对 arXiv 原文、插图和 ar5iv 公开数据的授权单独确认。开源软件许可证不等于论文内容再分发许可证。
