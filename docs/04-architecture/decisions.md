## 设计风险与待验证假设

- [H] 主文件图分析能显著减少错误入口：需要定量比较 `00README/heuristics/trial` 的准确率。
- [H] 复用 LaTeXML 后，主要增益来自依赖修复与 quality gating：须通过对照实验验证。
- [H] PDF 交叉验证能发现 HTML 无声内容丢失：需避免 PDF OCR 自身误差导致误报。
- [H] LLM 修复微小 TeX 问题能提高可用性：先关闭，待安全回归后再做消融。

## 决策变更规则

每次更改记录背景、替代方案、数据、向后兼容、迁移策略。未经数据支持不把“技术偏好”转成质量事实。
